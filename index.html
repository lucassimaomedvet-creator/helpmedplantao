    Buscar medicamento

      Receita

        Adicione medicamentos pela busca ao lado (ou pelo botão "+ receita" nas patologias e na pediatria).

        Dose por peso

        As doses em mg/kg são editáveis. Confira apresentação, dose máxima e idade mínima antes de prescrever.

        Calculadoras clínicas

        Idade, peso e sexo vêm do atendimento. Cada resultado tem uma linha pronta para o prontuário.

        Ativar a IA

        ⚠️ A chave salva está incompleta (a lista de chaves só mostra uma versão abreviada). Crie uma chave nova e, na janela que aparece logo depois, clique em Copy — a chave completa só aparece ali, uma vez.

        1. Crie uma chave grátis do Gemini em aistudio.google.com → Get API key → Create API key (começa com AIza).
        2. No Terminal, na pasta prontuario-rapido, rode ./salvar-chave.sh e cole a chave
        3. Avise o Claude (ou reinicie o app) para ativar.
